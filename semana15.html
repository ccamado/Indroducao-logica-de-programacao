📙 Revisão — Semana 15 (21/05) — Vetor

Revisão para reforçar vetor, índice e maior/menor.

O que é vetor?
  • Vetor é uma lista em 1 dimensão (uma sequência).
  • Cada posição tem um índice (0, 1, 2...).
  • Serve para guardar vários valores do mesmo tipo (ex.: notas).
PARA i DE 0 ATÉ 4 FAÇA
    LEIA(notas[i])
FIMPARA
Maior e menor (ideia do algoritmo)
  • Comece com maior = primeiro e menor = primeiro.
  • Percorra o vetor comparando e atualizando.
  • No final, mostre maior e menor.
maior <- notas[0]
menor <- notas[0]
PARA i DE 1 ATÉ 4 FAÇA
    SE (notas[i] > maior) ENTAO maior <- notas[i]
    SE (notas[i] < menor) ENTAO menor <- notas[i]
FIMPARA
Entregável (revisão)
  • Pseudocódigo: ler 5 notas em um vetor e mostrar maior e menor.
📝 Resumo para copiar no caderno
1) Vetor = lista em 1 dimensão (sequência).
2) Índice = posição (0,1,2...).
3) Para ler/percorrer vetor, use PARA.
4) Para maior/menor: compare e atualize durante o percurso.
