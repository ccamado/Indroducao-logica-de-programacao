⭐ Aula de Hoje — Semana 16 (28/05) — Matriz (3x3)

Aula do dia: matriz e soma da diagonal principal.

O que é matriz?
  • Matriz é uma tabela com linhas e colunas.
  • Uma matriz 3x3 tem 3 linhas e 3 colunas (9 valores).
  • A posição é (linha, coluna).
PARA lin DE 0 ATÉ 2 FAÇA
    PARA col DE 0 ATÉ 2 FAÇA
        LEIA(m[lin][col])
    FIMPARA
FIMPARA
Diagonal principal (3x3)
  • Diagonal principal: (0,0), (1,1), (2,2).
  • Somar diagonal = m[0][0] + m[1][1] + m[2][2].
  • Você pode somar com um PARA usando i.
somaDiag <- 0
PARA i DE 0 ATÉ 2 FAÇA
    somaDiag <- somaDiag + m[i][i]
FIMPARA
Entregável (aula de hoje)
  • Matriz 3x3 (preencher) + soma da diagonal principal.
📝 Resumo para copiar no caderno

2) Matriz 3x3 tem 9 valores.
3) Diagonal principal: (0,0), (1,1), (2,2).
4) Somar diagonal: somaDiag += m[i][i].
