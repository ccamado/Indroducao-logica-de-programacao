📘 Semana 17 — Lista, Fila e Pilha (FIFO/LIFO)

Hoje vamos diferenciar lista, fila e pilha com exemplos do cotidiano e praticar no Portugol Web Studio.

Conceitos rápidos
  • Lista: coleção em sequência (você pode inserir/remover em posições).
  • Fila: FIFO — primeiro entra, primeiro sai (ex.: cantina).
  • Pilha: LIFO — último entra, primeiro sai (ex.: pratos).
🧪 Prática no Portugol Web Studio (portugol.dev)

Abra: https://portugol.dev/

  • Passo 1 — Abrir e preparar: clique em Novo (ou “Novo Projeto”) e apague tudo do editor.
  • Passo 2 — Copie e cole o código-base abaixo e clique em Executar.
  • Passo 3 — Confira a saída esperada:
    • FILA: Ana → Bruno → Carla
    • PILHA: C → B → A
    • Conclusão: FILA = FIFO e PILHA = LIFO
  • Passo 4 — Mini-desafio (guiado): troque a fila para Davi, Ester, Felipe e a pilha para X, Y, Z. Execute e confira:
    • Fila sai: Davi → Ester → Felipe
    • Pilha sai: Z → Y → X
  • Passo 5 — Comentário obrigatório: no final do código, cole: 
    // FILA = FIFO: Primeiro Entra, Primeiro Sai (ex.: fila da cantina)
// PILHA = LIFO: Ultimo Entra, Primeiro Sai (ex.: pilha de pratos)
📌 Código-base para copiar e colar
programa {
  funcao inicio() {
    cadeia fila1, fila2, fila3
    cadeia topo1, topo2, topo3

    // ===== FILA (FIFO) =====
    fila1 = "Ana"
    fila2 = "Bruno"
    fila3 = "Carla"

    escreva("=== FILA (FIFO) ===\n")
    escreva("Entraram na fila: ", fila1, ", ", fila2, ", ", fila3, "\n")
    escreva("SAIDA (atendimento): ", fila1, " -> ", fila2, " -> ", fila3, "\n\n")

    // ===== PILHA (LIFO) =====
    topo1 = "A"
    topo2 = "B"
    topo3 = "C"

    escreva("=== PILHA (LIFO) ===\n")
    escreva("Empilhados: ", topo1, ", ", topo2, ", ", topo3, "\n")
    escreva("SAIDA (desempilhar): ", topo3, " -> ", topo2, " -> ", topo1, "\n\n")

    escreva("Conclusao:\n")
    escreva("- FILA = FIFO (Primeiro Entra, Primeiro Sai)\n")
    escreva("- PILHA = LIFO (Ultimo Entra, Primeiro Sai)\n")
  }
}
📝 Resumo para copiar no caderno
1) Lista = coleção em sequência (adiciona/remove).
2) Fila (FIFO) = primeiro entra, primeiro sai.
3) Pilha (LIFO) = último entra, primeiro sai.
4) Exemplos: cantina (fila) e pratos (pilha).
