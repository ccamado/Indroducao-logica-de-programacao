📘 Revisão — Semana 13 (07/05) — Funções

Revisão rápida para reforçar: função, parâmetro, argumento e retorno.

O que é uma função?
  • Função é um pedaço de algoritmo com nome.
  • Você usa a mesma lógica várias vezes sem reescrever tudo.
  • Ela recebe entrada, faz um processo e devolve um retorno.
FUNCAO dobro(x)
    // devolve o dobro
    RETORNE(x * 2)
FIMFUNCAO
Parâmetro x Argumento
  • Parâmetro = nome dentro da função (ex.: x).
  • Argumento = valor enviado na chamada (ex.: 5).
  • Retorno = valor devolvido (ex.: 10).
resultado <- dobro(5)
// x é parâmetro; 5 é argumento
// resultado recebe o retorno
Entregável (revisão)
  • Faça no caderno: 2 funções (dobro e média) + comentários.
FUNCAO media(a, b)
    // devolve a média
    RETORNE((a + b) / 2)
FIMFUNCAO
📝 Resumo para copiar no caderno
1) Função = mini-algoritmo reutilizável.
2) Parâmetro é o nome da entrada (x, a, b).
3) Argumento é o valor enviado (5, 6, 8).
4) Retorno é o valor devolvido para usar depois.
5) Ex.: dobro(x)=x*2; media(a,b)=(a+b)/2.
