📗 Revisão — Semana 14 (14/05) — Retorno & Reuso

Revisão para consolidar retorno e reutilização.

Retorno (o mais importante)
  • Retornar é DEVOLVER um valor para quem chamou a função.
  • O retorno pode ser guardado em variável (x <- funcao(...)).
  • Mostrar (ESCREVA/print) é diferente: é só exibir na tela.
FUNCAO soma(a, b)
    RETORNE(a + b)
FIMFUNCAO

x <- soma(3, 4)
Reutilização (por que ajuda)
  • Se você repete a mesma lógica (média, desconto, dobro), crie uma função.
  • Depois é só chamar para vários casos (vários alunos).
  • Isso deixa o algoritmo menor e mais organizado.
PARA aluno DE 1 ATÉ 3 FAÇA
    LEIA(n1)
    LEIA(n2)
    m <- media(n1, n2)
    ESCREVA(m)
FIMPARA
Entregável (revisão)

📝 Resumo para copiar no caderno
1) Mostrar = exibir na tela; Retornar = devolver valor para usar.
2) Retorno pode ser guardado em variável: x <- funcao(...).
3) Reutilizar = chamar a mesma função várias vezes.
4) Funções deixam o algoritmo menor e mais organizado.
